# Utilidade: **Tipo Solicitação**

Você pode utilizar a constante de tipo solicitação p/ melhor legibilidade do seu código, por exemplo:

```typescript
// ES Modules ou TypeScript:
import { TipoSolicitacao } from "@brainydigital/intima.ai-sdk-typescript";

// CommonJS (Node.js tradicional):
const { TipoSolicitacao } = require("@brainydigital/intima.ai-sdk-typescript");

const tipoSolicitacao = TipoSolicitacao.HABILITACAO_SIMPLES;
```

Abaixo, está a tabela com todos os valores possíveis para a constante de tipo solicitação.

| Constante           | Valor |
| ------------------- | ----- |
| HABILITACAO_SIMPLES | 0     |
