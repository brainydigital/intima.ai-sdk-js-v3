# Utilidade: **Dia**

Você pode utilizar a constante de dia p/ melhor legibilidade do seu código, por exemplo:

```typescript
// ES Modules ou TypeScript:
import { Dia } from "@brainydigital/intima.ai-sdk-typescript";

// CommonJS (Node.js tradicional):
const { Dia } = require("@brainydigital/intima.ai-sdk-typescript");

const dia = Dia.SEGUNDA_FEIRA;
```

Abaixo, está a tabela com todos os valores possíveis para a constante de dia.

| Constante     | Valor |
| ------------- | ----- |
| DOMINGO       | 0     |
| SEGUNDA_FEIRA | 1     |
| TERCA_FEIRA   | 2     |
| QUARTA_FEIRA  | 3     |
| QUINTA_FEIRA  | 4     |
| SEXTA_FEIRA   | 5     |
| SABADO        | 6     |
