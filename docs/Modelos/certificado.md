# Modelo: **Certificado**

Você pode instanciar um certificado, utilizada em métodos em que a mesmo é necessário.

```typescript
// ES Modules ou TypeScript:
import { Certificado } from "@brainydigital/intima.ai-sdk-typescript";

// CommonJS (Node.js tradicional):
const { Certificado } = require("@brainydigital/intima.ai-sdk-typescript");

const certificado = new Certificado(
  "caminho/do/certificado",
  "senha-do-certificado"
);
```
